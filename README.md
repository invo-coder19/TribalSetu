# Tribalsetu

### One Platform. Every Scholarship Journey. Simplified.

<p align="center">
<strong>A unified mobile-first scholarship experience designed to simplify scholarship discovery, eligibility, verification, and tracking.</strong>
</p>

---

## 🌟 Overview
Students often have to navigate multiple scholarship portals, repeatedly submit documents, manually check eligibility, and track applications across different systems. 

**Tribalsetu** brings the essential parts of this journey together in one simple mobile application. Our prototype focuses on creating a student-friendly experience where you can discover scholarships, verify eligibility, manage documents, and track applications effortlessly.

## ✨ Core Features

*   **🎯 Eligibility Radar**: Automatically analyzes student profiles to highlight matching scholarship opportunities.
*   **🔐 Zero-Reupload Verification**: Verify documents once and reuse them across multiple eligible scholarship applications.
*   **📊 Scholarship 360**: A consolidated dashboard providing a complete view of active applications, document statuses, and received payments.
*   **🤖 JAGO Assistant**: An AI-powered personal assistant to help students with eligibility queries, document requirements, and status tracking.
*   **🔔 Unified Updates**: Centralized notifications for application statuses, document verification, and payment updates.
*   **👤 Comprehensive Profile**: A unified view of personal, academic, and scholarship-related information.

## 🏗️ Architecture & Tech Stack

This repository contains a **static but interactive Android prototype** built to demonstrate the complete student experience.

*   **Language:** Kotlin
*   **UI Framework:** Jetpack Compose (Material 3)
*   **Navigation:** Navigation Compose
*   **Platform:** Android
*   **IDE:** Android Studio

## 🚀 Getting Started

### Requirements
*   Android Studio
*   Android SDK
*   Compatible JDK
*   Git

### Installation
1.  **Clone the Repository**
    ```bash
    git clone https://github.com/invo-coder19/TribalSetu.git
    ```
2.  **Open the Project**: Open the cloned folder in Android Studio and allow Gradle synchronization to complete.
3.  **Build the Project**: `Build → Make Project` (or `Ctrl + F9`)
4.  **Run**: Connect an Android device or start an emulator and press `▶ Run`.

## 🔮 Future Scope
The prototype is designed to scale into a production-ready platform through integration with authoritative systems like DigiLocker, UDISE+, APAAR, and state e-District services. Future updates aim to include secure document verification, real-time tracking, DBT integrations, and beneficiary gap detection.

## 🔒 Security
Production implementation will prioritize secure authentication, encrypted communication, role-based access control, consent-based data sharing, and compliance with government data protection standards.
